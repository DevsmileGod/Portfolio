How I think

Measure, then optimize.

Every speed-up starts with a profile and ends with an accuracy check. A faster model that stops seeing is not faster.

Production is the test.

A model is done when it runs on the target hardware, at the target latency, for the people who depend on it.

Build what people adopt.

A tool proves itself when engineers choose to use it. I build for the person on the other end of the API.
